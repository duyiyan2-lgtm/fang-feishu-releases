# 上传说明

本目录来自本地归档 `01-完整项目源码`，已去掉 GitHub 无法接收或不适合入库的内容：

- `.git/`：内部 pack 约 247MB，超过 GitHub 单文件 100MB 限制。完整 Git 历史仍在 Gitee。

- `clients/web-desktop/release/win-unpacked/`：未打包运行目录，含超过 100MB 的 exe。

源码、文档、历史发布分片和 100MB 以下的安装包已保留。
