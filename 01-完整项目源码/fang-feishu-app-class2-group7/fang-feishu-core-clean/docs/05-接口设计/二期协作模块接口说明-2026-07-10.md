# 二期协作模块接口说明

> 所有接口前缀：`/api/v1`  
> 除登录和注册外，均需：`Authorization: Bearer {token}`  
> 统一响应：`{ code, message, data, traceId }`

## 云文档

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| PUT | `/documents/{id}/collaborators` | 替换协作者；`{ userIds, permission: "View"|"Edit" }` |
| GET | `/documents/{id}/collaborators` | 查询协作者 |
| PATCH | `/documents/{id}/visibility` | 设置 `Organization` 或 `Private` |
| POST | `/documents/{id}/versions/{versionId}/restore` | 恢复历史版本 |
| DELETE | `/documents/{id}` | 删除文档，仅所有者或管理员 |

私有文档仅所有者、协作者和管理员可访问；组织文档所有登录用户可查看，所有者、编辑协作者和管理员可编辑。

## 知识库

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/wiki/spaces` | 知识库空间列表、创建 |
| GET / PUT / DELETE | `/wiki/spaces/{spaceId}` | 空间详情、修改、删除 |
| GET / PUT | `/wiki/spaces/{spaceId}/members` | 查询或替换空间成员 |
| GET / POST | `/wiki/spaces/{spaceId}/nodes` | 查询或新增目录节点 |
| PUT / DELETE | `/wiki/spaces/{spaceId}/nodes/{nodeId}` | 修改或删除节点 |

空间成员权限为 `View`、`Edit`、`Admin`；节点可关联已有文档 `documentId`。

## IM

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/im/messages/search?keyword=...&conversationId=...` | 在本人可访问会话中搜索消息 |
| POST | `/im/messages/{messageId}/reactions` | 添加回应，`{ reactionType }` |
| DELETE | `/im/messages/{messageId}/reactions/{reactionType}` | 删除自己的回应 |
| GET / PUT | `/im/conversations/{id}/announcement` | 查询或修改群公告，群主/管理员可修改 |
| GET | `/im/conversations/{id}/read-receipts` | 查询群成员已读位置 |

发送消息可额外传入 `mentionUserIds`，仅允许指定会话成员；被提及用户会收到“被提及”通知。消息对象新增 `reactions[]`、`mentionUserIds[]`。回应变化通过 IM Hub 事件 `MessageReactionUpdated` 推送。

## 日程

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST / PUT | `/calendar/events`、`/calendar/events/{id}` | 请求体可附带 `attendeeUserIds` |
| PATCH | `/calendar/events/{id}/attendance` | 受邀人设置 `Accepted`、`Declined`、`Tentative` |
| GET | `/calendar/events/free-busy?userIds=...&from=...&to=...` | 查询忙闲时间段 |
| GET | `/calendar/events/{id}/occurrences?from=...&to=...` | 查询周期日程实例 |

创建或编辑请求可附带 `recurrenceType: None|Daily|Weekly|Monthly` 和 `recurrenceUntil`。创建人可修改参与者；受邀人会收到 `Calendar` 通知。

## 审批

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/approvals/templates` | 查询或创建审批模板，创建仅管理员 |
| GET / PUT / DELETE | `/approvals/templates/{id}` | 模板详情、修改、删除 |
| POST | `/approvals` | `templateId` 可选；使用模板时按步骤顺序流转 |
| POST | `/approvals/{id}/withdraw` | 申请人撤回待审批申请 |
| POST | `/approvals/{id}/remind` | 申请人催办待审批申请 |

提交审批时可选传 `ccUserIds`，抄送人会收到 `Approval` 通知，审批详情会返回 `ccUserIds`。

模板请求示例：

```json
{
  "name": "请假审批",
  "type": "Leave",
  "description": "按主管、HR 顺序审批",
  "approverUserIds": ["主管 UUID", "HR UUID"],
  "isActive": true
}
```

## 云盘

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/files/folders` | 文件夹列表、创建 |
| PUT / DELETE | `/files/folders/{id}` | 重命名/移动、删除空文件夹 |
| PATCH | `/files/{id}/move` | 移动文件，`{ folderId }` |
| GET / PUT | `/files/{id}/shares` | 查看或替换分享用户 |
| DELETE | `/files/{id}` | 移入回收站 |
| GET | `/files/trash` | 查询回收站 |
| POST | `/files/{id}/restore` | 恢复文件 |
| DELETE | `/files/{id}/permanent` | 永久删除回收站文件 |
| GET | `/files/{id}/preview` | 按原 Content-Type 以内联形式预览文件 |

上传接口 `POST /files/upload` 可选 multipart 字段 `folderId`。分享权限为 `View` 或 `Edit`；目前下载权限已生效，编辑权限为后续在线编辑文件预留。

## 视频会议

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/meetings` | 可带 `scheduledStartAt`、`scheduledEndAt` 创建排期会议 |
| PATCH | `/meetings/{id}/schedule` | 修改会议排期 |
| GET / POST | `/meetings/{id}/chat` | 查询或发送会议内消息 |
| GET | `/meetings/{id}/statistics` | 查询邀请数、参会数、在线数和平均参会时长 |

会议音视频画面由客户端接入 Agora。后端 `join` 接口负责成员校验和返回房间/令牌；正式使用须配置 `Agora:AppId` 与 `Agora:AppCertificate`。

## 前端联调顺序

1. 先部署最新版后端并确认 Swagger 出现以上路径。
2. 文档和知识库先完成权限与目录页。
3. IM、日程、审批、云盘、会议按各自列表页再到详情页的顺序联调。
4. 测试至少使用两个普通账号和一个管理员账号验证权限差异。
