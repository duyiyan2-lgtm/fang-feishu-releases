# 飞书能力差距与本次补充

> 更新日期：2026-07-10  
> 范围：仿飞书协同办公平台 MVP 后端（不是完整商业飞书复刻）

## 一、当前已覆盖的核心能力

| 模块 | 已具备能力 |
| --- | --- |
| 账号与组织 | 登录、注册、退出、JWT、用户、角色、部门、通讯录、操作日志 |
| 即时通讯 | 单聊、群聊、历史消息、发送、撤回、未读数、已读回执、@成员、群公告、消息搜索、表情回应、SignalR 推送 |
| 文档 | 列表、创建、编辑、详情、可见范围、协作者、评论、评论查询/删除、版本记录与恢复 |
| 知识库 | Wiki 空间、成员权限、目录节点、文档关联 |
| 云盘 | 文件夹、上传、下载、预览、移动、分享、回收站、恢复、永久删除，本地或 MinIO 存储 |
| 日程 | 个人日程、周期实例、邀请参与者、接受/拒绝/暂定、忙闲查询 |
| 审批 | 模板、顺序审批、提交、通过、驳回、撤回、催办、抄送、审批记录 |

| 任务中心 | 创建、指派、查询、编辑、状态流转、完成、重新打开、删除 |

## 二、本次新增接口

### 1. 任务中心

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/tasks?scope=all&status=Todo` | 查询与当前用户相关的任务；`scope` 可为 `all`、`assigned`、`created` |
| POST | `/api/v1/tasks` | 创建任务并可指派负责人 |
| GET | `/api/v1/tasks/{id}` | 查询任务详情 |
| PUT | `/api/v1/tasks/{id}` | 创建人或管理员修改任务标题、描述、负责人、截止时间 |
| PATCH | `/api/v1/tasks/{id}/status` | 更新为 `Todo`、`InProgress`、`Completed` |
| PATCH | `/api/v1/tasks/{id}/complete` | 完成任务 |
| PATCH | `/api/v1/tasks/{id}/reopen` | 重新打开任务 |
| DELETE | `/api/v1/tasks/{id}` | 创建人或管理员删除任务 |

创建示例：

```json
{
  "title": "整理联调记录",
  "description": "补齐小程序端回归结果",
  "assigneeId": "用户 UUID",
  "dueAt": "2026-07-12T18:00:00+08:00"
}
```

任务被指派给其他用户时，系统会产生 `type=Task` 的站内通知，通知中包含 `resourceType=Task` 和 `resourceId`。

### 2. 群成员管理

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| POST | `/api/v1/im/conversations/{id}/members` | 按群设置决定所有成员或群主/管理员可邀请 |
| DELETE | `/api/v1/im/conversations/{id}/members/{userId}` | 按群设置决定；管理员只能由群主移除 |
| POST | `/api/v1/im/conversations/{id}/leave` | 普通成员或管理员退出；群主需先解散或转让群主 |

邀请成员请求：

```json
{
  "memberUserIds": ["用户 UUID 1", "用户 UUID 2"]
}
```

群成员、管理员、群名、头像、权限设置变化后，后端会推送 `ConversationUpdated`。

### 3. 文档评论

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/documents/{id}/comments` | 查询文档全部评论 |
| DELETE | `/api/v1/documents/{documentId}/comments/{commentId}` | 评论作者、文档所有者或管理员可删除 |

非文档所有者发表评论时，会向文档所有者发出 `type=Document` 通知。

### 4. 通知契约统一

`GET /api/v1/notifications/unread-count` 统一返回：

```json
{
  "code": 0,
  "message": "success",
  "data": { "unreadCount": 3 }
}
```

通知列表额外返回 `resourceType` 与 `resourceId`。前端应优先据此跳转到聊天、审批、文档、会议或任务详情，不再只依赖 `type` 猜测跳转位置。

## 三、IM Hub 事件契约

连接地址：`/hubs/im?access_token={JWT}`。

| 事件 | Payload 核心字段 | 使用时机 |
| --- | --- | --- |
| `ReceiveMessage` | `id`、`conversationId`、`senderId`、`content`、`messageType`、`createdAt` | 收到新消息 |
| `MessageRecalled` | `id`、`conversationId` | 消息被撤回 |
| `ConversationUpdated` | 完整会话对象，含 `members`、`ownerId`、`adminIds`、`settings` | 群信息、成员或管理员发生变化 |
| `ConversationRemoved` | `conversationId` | 当前用户被移出群聊或主动退出 |
| `ConversationDissolved` | `conversationId` | 群聊被解散 |
| `MessageReactionUpdated` | 完整消息对象，含 `reactions` | 消息回应发生变化 |

## 四、仍未实现的飞书能力

以下能力属于真实飞书产品具备、但不适合本次 10 天 MVP 直接扩展的范围。它们不是当前验收阻塞项。

| 模块 | 尚缺能力 | 原因 / 后续建议 |
| --- | --- | --- |
| 云文档 | 多人同时编辑、光标协作、@提及、分享链接 | 需要 OT/CRDT 和实时协同编辑器 |
| 知识库 | 页面归档、跨空间移动、全文检索 | 可在前端页面稳定后逐项增加 |
| IM | 消息置顶、转发 | 当前已有 @成员、公告和已读回执 |
| 日历 | 会议室预订、定时提醒 | 周期日程已支持；提醒需后台任务服务 |
| 云盘 | 收藏、文件版本 | 文件预览、文件夹、分享和回收站已完成 |
| 审批 | 条件分支、表单设计器 | 当前已有顺序模板、撤回、催办和抄送 |
| 视频会议 | 屏幕共享、录制、会议纪要 | 参会统计已支持；屏幕共享和录制依赖 Agora 客户端及云端能力 |
| 企业服务 | 邮箱、考勤、OKR、招聘、报销、薪酬、SSO、机器人和开放平台 | 超出课程项目范围，通常依赖额外外部服务 |
| 平台能力 | 全局搜索、Webhook、开放 API、审计告警、细粒度菜单权限 | 可在系统稳定后按管理需求增加 |

## 五、部署注意事项

本次新增协作者、知识库、消息回应、日程参与者、审批模板、云盘目录/分享、会议聊天等表，并给旧表补充需要的字段。当前启动逻辑会在 PostgreSQL 环境下自动补表和补列。

部署新版时需确认：

1. 使用本项目最新版后端目录。
2. 首次升级启动时保持 `Database:AutoCreate=true`，确保自动执行结构补齐。
3. 启动后访问 `/swagger`，确认出现 `/api/v1/wiki`、`/api/v1/tasks`、群成员、文档协作者、日程参与者、审批模板、云盘目录和会议聊天接口。
4. 视频会议实际入会前需配置有效的 `Agora:AppId` 和 `Agora:AppCertificate`。
