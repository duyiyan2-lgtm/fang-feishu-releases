# 05 · 接口设计

## 🎯 阶段目标

基于需求与数据库设计，输出**RESTful 风格、版本化、统一错误码**的 OpenAPI 3.0 接口契约，前端联调与后端开发均以此为基线。

## 📝 必含章节（每篇接口设计文档）

| 章节 | 说明 | 必含配图 |
| :--: | :-- | :--: |
| 一、接口概述 | 模块 / 资源 / 路径 | ✅ |
| 二、统一规范 | 鉴权 / 响应结构 / 错误码 / 分页 | ✅ |
| 三、接口列表 | Method + Path + 鉴权 + 限流 | ❌ |
| 四、字段定义 | 请求/响应字段（嵌套结构用表格） | ✅ |
| 五、时序图 | 关键接口的时序图 | ✅ |
| 六、错误场景 | 错误码 + 触发条件 + 提示文案 | ❌ |
| 七、Mock 数据 | 示例请求/响应 | ❌ |

## 📂 命名规范

```
05-接口设计-<模块名>-<资源名>.md
```

示例：
- `05-接口设计-IM-消息.md`
- `05-接口设计-用户中心-认证.md`

- 状态机图
- 字段嵌套结构图
