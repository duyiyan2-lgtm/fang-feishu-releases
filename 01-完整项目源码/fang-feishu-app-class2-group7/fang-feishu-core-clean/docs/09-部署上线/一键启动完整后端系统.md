# 一键启动完整后端系统

## 目标

本说明用于一键启动后端完整运行环境，包括：

- ASP.NET Core API
- PostgreSQL 16
- MinIO 文件存储
- Swagger 接口文档
- 自动初始化演示数据

## 前置条件

- 已安装 Docker Desktop
- Docker Desktop 已启动
- 本机端口 `5080`、`55432`、`9000`、`9001` 未被占用

## 一键启动

在项目根目录执行：

```powershell
.\backend\scripts\start-full.ps1
```

首次启动会自动构建后端镜像，时间会稍长。

启动成功后访问：

- API 健康检查：http://127.0.0.1:5080/health
- Swagger：http://127.0.0.1:5080/swagger
- MinIO 控制台：http://127.0.0.1:9001

MinIO 默认账号：

```text
minioadmin / minioadmin
```

## 默认演示账号

```text
admin / 123456
user_a / 123456
user_b / 123456
user_c / 123456
user_d / 123456
```

## 停止系统

```powershell
.\backend\scripts\stop-full.ps1
```

## 重置数据后重新启动

此命令会删除 PostgreSQL 和 MinIO 的 Docker 卷，适合演示前重置环境：

```powershell
.\backend\scripts\start-full.ps1 -Reset
```

## 服务端口

| 服务 | 容器端口 | 本机端口 | 说明 |
| --- | --- | --- | --- |
| API | 8080 | 5080 | 后端业务接口 |
| PostgreSQL | 5432 | 55432 | 数据库 |
| MinIO API | 9000 | 9000 | 对象存储接口 |
| MinIO Console | 9001 | 9001 | 文件存储控制台 |
