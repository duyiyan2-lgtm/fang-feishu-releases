## 三、建议部署步骤

```powershell
cd backend
dotnet restore
dotnet build FangFeishu.Backend.sln
dotnet test FangFeishu.Backend.sln
dotnet publish src/FangFeishu.Api/FangFeishu.Api.csproj -c Release -o publish
```

如果服务器使用 EF Core Migration：

```powershell
dotnet ef database update --project src/FangFeishu.Api/FangFeishu.Api.csproj --startup-project src/FangFeishu.Api/FangFeishu.Api.csproj
```

如果服务器仍使用当前演示环境自动建表：

```text
确认 appsettings.json 中 Database:AutoCreate = true
首次启动会自动创建表并写入演示数据
```
