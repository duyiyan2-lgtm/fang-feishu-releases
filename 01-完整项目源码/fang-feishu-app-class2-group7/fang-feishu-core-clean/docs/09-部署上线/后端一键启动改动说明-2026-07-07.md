# 后端一键启动改动说明

## 一、改动目标

本次改动的目标是让后端从“本地手动启动 API + Docker 启动依赖”升级为“Docker Compose 一键启动完整后端系统”。

一键启动后包含：

- ASP.NET Core 后端 API
- PostgreSQL 数据库
- MinIO 文件存储
- Swagger 接口文档
- 后端初始化演示数据

这样前端、测试、运维成员只需要执行一个脚本，就可以启动完整后端环境，方便联调和验收演示。

## 二、本次新增文件

| 文件 | 作用 |
| --- | --- |
| `.dockerignore` | 排除 Docker 构建时不需要的目录，如 `.git`、`bin`、`obj`、`storage` 等，减少镜像构建上下文 |

| `docs/09-部署上线/一键启动完整后端系统.md` | 面向使用者的启动、停止、重置和访问说明 |
| `docs/09-部署上线/后端一键启动改动说明-2026-07-07.md` | 本文件，用于说明本次改动内容 |

## 三、本次修改文件

| 文件 | 修改内容 |
| --- | --- |
| `deploy/docker/docker-compose.dev.yml` | 新增 `api` 服务，将后端 API 纳入 Docker Compose；补充 PostgreSQL 健康检查；配置 API 连接容器内 PostgreSQL 和 MinIO |
| `backend/scripts/reset-dev.ps1` | 保留本地开发模式，只启动 PostgreSQL 和 MinIO，不再默认启动 API 容器 |

## 四、Docker Compose 改动说明

### 1. 新增 API 服务

新增服务名：

```yaml
api
```

API 容器对外暴露端口：

```text
5080 -> 8080
```

启动后访问：

```text
http://127.0.0.1:5080
```

Swagger 地址：

```text
http://127.0.0.1:5080/swagger
```

### 2. API 容器连接数据库

容器内不再使用本机地址 `127.0.0.1`，而是使用 Docker Compose 服务名：

```text
Host=postgres;Port=5432;Database=fang_feishu;Username=fang_feishu;Password=fang_feishu_pwd
```

这样 API 容器可以稳定访问 PostgreSQL 容器。

### 3. API 容器连接 MinIO

MinIO 地址改为容器内服务名：

```text
minio:9000
```

文件存储方式配置为：

```text
Storage__Provider=Minio
```

后端上传的文件会进入 MinIO。

### 4. 新增数据库健康检查

PostgreSQL 增加了 `healthcheck`：

```yaml
pg_isready -U fang_feishu -d fang_feishu
```

API 服务会等待 PostgreSQL 健康后再启动，减少启动顺序导致的连接失败。

## 五、脚本使用说明

### 一键启动完整后端

在项目根目录执行：

```powershell
.\backend\scripts\start-full.ps1
```

首次启动会自动构建后端 Docker 镜像。

### 重置数据并重新启动

```powershell
.\backend\scripts\start-full.ps1 -Reset
```

该命令会删除 PostgreSQL 和 MinIO 的 Docker 卷，适合演示前恢复干净环境。

### 停止完整后端

```powershell
.\backend\scripts\stop-full.ps1
```

### 停止并删除数据卷

```powershell
.\backend\scripts\stop-full.ps1 -RemoveVolumes
```

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| 后端 API | `http://127.0.0.1:5080` | 后端服务根地址 |

```text
minioadmin / minioadmin
```

user_a / 123456

## 八、前端联调说明

```text
http://127.0.0.1:5080/api/v1
```

SignalR IM 地址：

```text
http://127.0.0.1:5080/hubs/im
```

前端联调时只需要把接口基础地址从本地 `dotnet run` 地址切换为 `http://127.0.0.1:5080`。
