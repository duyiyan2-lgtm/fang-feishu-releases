# 后端测试与收尾说明

本说明用于补充后端开发收尾记录，重点说明当前后端已完成的测试、脚本、联调状态和后续仍需运维配合的事项。

## 五、收尾阻塞

当前本地代码已经支持：

```text
POST /api/v1/auth/logout
JWT Token 撤销校验
Local / MinIO 文件存储切换
```

但线上服务器仍需同步最新后端版本。2026-07-07 回归结果显示：

```text
POST http://120.76.54.147/api/v1/auth/logout -> 404
```

结论：

```text
这不是本地代码缺失，而是服务器部署版本未更新，需要运维或有服务器权限的同学重新部署。
```
