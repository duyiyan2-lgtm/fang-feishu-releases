## 三、部署状态结论

线上 `/health` 正常，但线上 Swagger 中尚未出现新版接口，例如：

- `/api/v1/tasks`
- `/api/v1/wiki/...`
- 文档协作者、消息回应、日程参与者接口
- 审批模板、云盘文件夹/分享、会议聊天接口

结论：当前服务器运行的是旧版本后端，旧版本核心接口可用；本地 V1.1 最新接口尚未部署到服务器，因此暂不能对新版进行线上 HTTP 联调验收。

## 四、本机真实 HTTP 测试限制

本地 Docker Desktop 未运行，项目默认开发数据库端口 `55432` 不可访问。机器上虽有 PostgreSQL 16 服务监听 `5432`，但没有项目数据库可用账号密码，未直接连接以避免影响现有数据。
