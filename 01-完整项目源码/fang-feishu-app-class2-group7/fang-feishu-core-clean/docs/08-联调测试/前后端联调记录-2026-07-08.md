### 5. 审批模块

审批模块接口已通过：

```text
GET /approvals
POST /approvals
PATCH /approvals/{id}/approve
PATCH /approvals/{id}/reject
```

注意事项：

- `GET /approvals` 返回审批列表，包含 `records[]` 审批记录。
- `POST /approvals` 请求体需要使用 `content` 字段：

```json
{
  "title": "Leave request",
  "type": "Leave",
  "content": "Request one day leave"
}
```

- 前端原先使用 `reason` 字段，需要改为 `content`。
- 审批通过和驳回需要管理员账号操作，请求体为：

```json
{
  "comment": "ok"
}
```

当前结论：

```text
审批模块接口联调通过，前端已正确适配 { title, type, content } 请求格式。
```
