# 小程序端 BUG 测试清单-2026-07-09

## 一、测试目标

本清单用于小程序端 BUG 测试，重点验证小程序在真机或微信开发者工具中是否能稳定完成核心业务流程。

本轮测试目标：

- 验证小程序端是否能正常访问 HTTPS 后端。
- 验证登录、通讯录、IM、文档、云盘等最低验收功能。
- 验证日程、审批、通知中心、管理后台等已接入功能是否稳定。
- 记录页面、接口、权限、兼容、体验类 Bug。

| 检查项 | 通过标准 |
| --- | --- |
| 页面 | 能正常打开，不白屏，不无限 loading |

| 鉴权 | 登录后请求自动携带 `Authorization: Bearer token` |

| 真机 | 真机扫码或体验版可正常请求 `https://alxy.fun` |
