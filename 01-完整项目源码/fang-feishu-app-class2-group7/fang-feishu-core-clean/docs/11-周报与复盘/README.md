# 11 · 周报与复盘

## 🎯 阶段目标

通过**日报、周报、阶段复盘**持续跟踪项目状态、沉淀经验教训、形成组织过程资产。

## 📝 必含章节

| 文档 | 必含内容 | 必含配图 |
| :--: | :-- | :--: |
| 日报 | 今日完成 / 今日计划 / 阻塞 | 进度截图 |
| 周报 | 本周亮点 / 数据 / 下周计划 | 燃尽图 |
| 月报 | 月度总结 + 关键指标 | 仪表盘 |
| 复盘 | 做得好的 / 改进的 / 行动项 | 不需要 |

## 📂 命名规范

```
日报-YYYY-MM-DD.md
周报-W{n}-YYYY.md
复盘-<阶段名>.md
```

示例：
- `日报-2026-07-15.md`
- `周报-W3-2026.md`
- `复盘-需求阶段.md`

## 🖼 配图要求

- 燃尽图（Burndown Chart）
- 进度截图（任务看板）
- 仪表盘（完成率、工时分布）
- 复盘文档可不配图

## 📦 产出物清单

- [ ] 每日日报（每人 1 份，共 14 周）
- [ ] 每周周报（每组 1 份，共 14 份）
- [ ] 阶段复盘（需求 / 开发 / 联调 / 上线 各 1 份）
- [ ] 项目总复盘（结项前）
