### 2. 明确接口适配规则

今日确认并记录了前端适配细节：

| 模块 | 适配说明 |
| --- | --- |
| IM 消息列表 | 返回分页结构 `{ page, pageSize, total, items }`，前端按 `items` 读取 |
| IM 发送消息 | 请求体直接传 `{ conversationId, content }` |
| 文档创建 | 请求体直接传 `{ title, content }`，不需要 `request` 包装 |
| 文件上传 | 使用 `multipart/form-data`，字段名为 `file` |
| 文件下载 | 返回文件流，不是统一 JSON 结构 |
| 日程 | 时间字段使用 ISO 8601 格式 |
| 审批 | 提交审批使用 `{ title, type, content }`，审批处理使用 `{ comment }` |

同时复核了审批模块字段问题，确认前端代码已正确使用 `content` 字段，之前 `reason` 是 curl 测试命令误写，不属于前端问题。
