## 二、遇到问题

1. **群主识别错误** — 首次群主显示"未知"，后显示为另一个成员。原因是前端用"第一个成员"做 fallback，但 API 不保证成员列表顺序
2. **解散群聊无权限** — 群主账号解散群聊失败，显示"无此权限"。后端解散接口可能未正确校验或未实现
3. **后端缺失关键字段** — `createdBy`（群主 ID）、`members[].role`（管理员标识）、`settings`（权限设置）后端均未返回，前端需多级策略推断群主，仍存在风险
4. **群管理 API 全缺** — 添加成员、移除成员、设置管理员、解散群聊等后端接口均未实现，前端页面完成但无法联调

## 三、解决情况

1. 群主识别改用系统入群消息（`__SYSTEM_GROUP_JOIN__`）的 `senderId` 推断，配合本地缓存 `group_owner_{convId}` 做二级 fallback
2. 解散群聊增加 4 种 fallback API 调用方式，并将错误信息展示给用户
3. 已整理完整后端 API 规范文档，标注缺失字段和接口，提交给后端团队参考
