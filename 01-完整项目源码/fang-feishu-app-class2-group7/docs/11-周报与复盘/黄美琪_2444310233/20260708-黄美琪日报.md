## 二、遇到问题

1. **云打包排队时间长** — DCloud 云打包高峰期排队半小时以上，且偶有打包被取消的情况
2. **云盘上传只支持图片** — 小程序端 `uni.chooseImage` 只能选择图片，无法上传其他文件类型
3. **文件路径中文导致命令行操作异常** — 项目路径含中文，`rm -rf`、`robocopy` 等命令在 Git Bash 下路径解析异常
4. **node_modules 部分文件被占用** — `.node` 文件在 Windows 下被进程锁定，`npm install` 无法完全清理旧目录
5. **HBuilderX 编译器模块缺失** — 替换项目文件后 `node_modules` 不完整，需重新 `npm install`

## 三、解决情况

1. 云打包虽然排队久但最终成功，后续考虑本地 Android Studio 离线打包作为备选
2. App 端改用 `uni.chooseFile` + `type: 'all'` 打开系统文件管理器，支持任意文件类型上传
3. 使用 PowerShell 和 `robocopy` 替代 Git Bash 命令处理中文路径文件操作
4. `npm install` 完成后忽略清理失败的临时目录，不影响使用
5. 完整执行 `npm install --legacy-peer-deps` 安装 605 个包，编译恢复正常
