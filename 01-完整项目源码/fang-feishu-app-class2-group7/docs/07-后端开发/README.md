# 07 · 后端开发

## 🎯 阶段目标

按模块/服务/接口**逐个交付** .NET 10 + ASP.NET Core + EF Core 实现，每个产出物必须配套完整开发文档。

## 📝 必含章节（每篇后端开发文档）

| 章节 | 说明 | 必含配图 |
| :--: | :-- | :--: |
| 一、功能概述 | 实现哪个需求、接口 | ❌ |
| 二、技术方案 | 分层、依赖、设计模式 | ✅ |
| 三、目录结构 | 项目结构、命名空间 | ✅ |
| 四、领域模型 | 实体、值对象、聚合根 | ✅ |
| 五、核心实现 | Controller / Service / Repository 关键代码 | ✅ |
| 六、数据库操作 | EF Core 迁移、查询优化 | ✅ |
| 七、单元测试 | 测试用例与覆盖率 | ✅ |
| 八、踩坑与复盘 | 问题 + 解决方案 | ❌ |

## 📂 命名规范

```
07-后端开发-<模块名>-<服务/接口名>.md
```

示例：
- `07-后端开发-IM-消息服务.md`
- `07-后端开发-用户中心-认证服务.md`
