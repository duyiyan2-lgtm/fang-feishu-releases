# 03 · 技术选型

## 🎯 阶段目标

通过系统化的技术调研、对比、PoC 验证，输出**可决策、可追溯**的技术选型清单（ADR - Architecture Decision Record）。

## 📝 必含章节（每篇选型文档）

| 章节 | 说明 | 必含配图 |
| :--: | :-- | :--: |
| 一、选型背景 | 要解决什么问题、约束条件 | ✅ |
| 二、候选方案 | 不少于 3 个候选方案 | ❌ |
| 三、对比维度 | 性能 / 生态 / 学习成本 / 团队契合度 / 长期维护 | ✅ |
| 四、对比矩阵 | 量化打分 + 加权总分 | ✅ |
| 五、PoC 验证 | 关键路径代码示例与结论 | ✅ |
| 六、决策结论 | 选 X 不选 Y 的理由 | ❌ |
| 七、风险与回退 | 选型风险 + 回退方案 | ❌ |

## 📂 命名规范

```
03-技术选型-<主题>.md
```

示例：
- `03-技术选型-前端框架.md`
- `03-技术选型-IM通信方案.md`
- `03-技术选型-数据库.md`

## 🖼 配图要求

- 候选方案架构图（每个方案 1 张）
- 对比雷达图 / 柱状图
- PoC 关键代码截图
- **≥ 5 张配图**

## 📦 产出物清单

- [ ] 前端框架选型
- [ ] 后端框架选型
- [ ] 数据库选型
- [ ] 中间件选型（缓存 / MQ / 搜索 / 对象存储）
- [ ] 部署方案选型
- [ ] 监控方案选型
- [ ] ADR 决策记录汇总（`03-技术选型-ADR汇总.md`）
