# 02 · 原型设计

## 🎯 阶段目标

基于需求文档，输出**高保真可交互原型**，明确页面布局、交互逻辑、视觉规范，作为前端开发的"施工图"。

## 📝 必含章节（每篇原型文档）

| 章节 | 说明 | 必含配图 |
| :--: | :-- | :--: |
| 一、设计目标 | 解决什么问题、参考产品 | ✅ |
| 二、页面清单 | 页面树状图、路由对应 | ✅ |
| 三、关键页面 | 核心页面的高保真原型 | ✅ |
| 四、交互说明 | 状态机、转场动效、异常态 | ✅ |
| 五、设计规范 | 颜色、字体、间距、组件库 | ✅ |
| 六、组件库清单 | 自研 / 复用组件清单 | ❌ |
| 七、设计交付物 | 切图、标注、设计稿链接 | ❌ |

## 📂 命名规范

```
02-原型设计-<模块名>-<页面名>.md
```

示例：
- `02-原型设计-IM-聊天窗口.md`
- `02-原型设计-通讯录-组织架构.md`

## 🖼 配图要求

- **核心页**：每页 1 张高保真图 + 多状态截图（加载/空/错误/成功）
- **总数量**：每篇文档 **≥ 8 张**（设计图比需求图更多）
- 存放：`docs/02-原型设计/images/` 子目录

## 📦 产出物清单

- [ ] 高保真原型（Figma / 墨刀 / Axure 源文件）
- [ ] 交互说明文档
- [ ] 设计规范（颜色/字体/组件）
- [ ] 切图与标注（Zeplin / 蓝湖）
- [ ] 四端适配说明（PC Web / PC Client / iOS / Android）
