# PC 与手机视频会议互通

测试包：`fang-feishu-android-v1.0.16-pc-mobile-meeting.apk`  
版本：`1.0.16`（versionCode `17`）

## 已完成

- Agora RTC UID 改为由“用户账号 + 客户端类型”生成。
  - 同一账号在 PC（Desktop/Web）和安卓端进入同一会议时会使用不同 UID，不会再互相挤掉。
  - 不同账号从 PC 和安卓端加入同一会议也继续使用同一频道互通。
- 手机端通知详情识别会议邀请，新增“加入视频会议”按钮。
- 手机端视频会议和通知页面自动刷新：PC 发起或邀请后，手机打开对应页面即可看到新会议/邀请。

## 重要：必须部署后端

本次不仅更新了安卓端，也修改了后端生成 Agora UID 的逻辑。只安装 APK 不足以解决同账号双端入会问题；需要将项目中 `backend` 的最新代码发布到实际运行的 API 服务并重启服务。

发布后按以下流程复测：

1. 用同一账号登录 PC 和安卓端（PC 使用 Desktop/Web 客户端类型，手机使用 Android）。
2. PC 创建或加入一个视频会议，并邀请该账号或所在群成员。
3. 安卓端打开“工作台 → 通知”，点击会议邀请中的“加入视频会议”；也可在“工作台 → 视频会议”中点击该会议。
4. 授予手机相机和麦克风权限。
5. 确认 PC 与手机能同时留在同一频道，双端音视频正常。
