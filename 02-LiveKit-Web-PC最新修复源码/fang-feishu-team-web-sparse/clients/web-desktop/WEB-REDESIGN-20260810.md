# Web 端界面优化记录（2026-08-10）

## 本次完成

- 重做主框架、侧边栏、顶部栏和全局明暗色视觉变量。
- 增加 `Ctrl/Cmd + K` 快速功能导航。
- 重做消息页的会话列表、消息气泡、输入区、空状态和会议入口。
- 恢复并保留自建 LiveKit，不再依赖 Agora。
- 重做视频会议页：头像占位、连接状态、参会人数、全屏、摄像头/麦克风控制和错误提示。
- 增加“页面流畅度”监测，综合页面 FPS、网络 RTT、网络类型、在线状态和长任务给出流畅/良好/一般/较差提示。
- 清理未使用的 Agora composable 与 4 份历史 Messages 测试页面。

## 第二轮性能与稳定性优化（2026-08-11）

- LiveKit SDK 和会议房间改为按需加载，未进入会议时不再下载 RTC 大包；消息页生产包由约 `65 KB` 降至约 `51 KB`。
- 消息发送改为乐观更新，弱网下点击发送可立即显示；发送失败会标记并恢复输入内容。
- 长会话使用浏览器延迟渲染，并把每个会话的本地缓存限制为最近 300 条，降低 DOM、内存和 localStorage 压力。
- `@成员` 输入改为读取真实光标位置，插入后准确恢复焦点，不再误聚焦页面中的其他输入框。
- 页面流畅度监测识别后台标签页，避免浏览器暂停动画帧时误报“卡顿”。
- LiveKit 视频轨道增加重复绑定保护，减少切换摄像头和参会人状态变化时的多余工作。
- 会议界面补充窄屏响应式布局，手机浏览器和小窗口下改为单列视频布局。
- 刷新依赖锁文件并修复生产依赖安全问题；`npm audit --omit=dev` 为 0 项漏洞。
- 加固 PC 客户端壳层：启用 Electron sandbox、生产环境禁用 DevTools、限制外链协议与页面跳转，并只向可信应用来源开放会议媒体权限。
- Electron 路由改为 hash 模式，修复桌面客户端刷新 `/messages` 等子页面可能白屏的问题；Web 部署仍使用 history 模式。
- 增加 CSP、安全元信息和正式应用图标，移除不存在的 Vite 默认图标引用。

## 第三轮实时通信与账号隔离修复（2026-08-11）

- 修复 SignalR 首次连接前切换会话时丢失群组订阅的问题；连接成功和自动重连后会重新加入当前会话。
- 增加实时连接状态通知、断线重试、重连后的会话列表与当前消息同步，减少必须退出聊天页再进入才能看到新消息的情况。
- 补齐好友申请收到、通过、拒绝及消息已读、会话更新等实时事件监听。
- 消息去重改为只按服务端消息 ID 判断，允许用户连续发送相同内容；历史消息同步改为合并缓存，接口临时失败时不再清空当前消息。
- 修复退出账号后旧用户缓存、旧 SignalR 连接和旧会话仍可能保留的问题，避免重新登录后显示 admin 或上一个账号的数据。
- 修复接口返回 401 时重复调用退出接口导致的状态竞争，并确保退出请求使用退出前的有效令牌。
- 修复首次打开群聊就发起会议时可能尚未加载群成员、从而漏发会议邀请的问题。
- 完善 LiveKit 音频节点清理、异常断开清理及重复入会取消逻辑，降低重复音频和会议资源泄漏风险。
- PC 构建增加正式生产 API 与 SignalR 地址，修复 `file://` 桌面客户端使用相对接口地址导致无法请求服务的问题。
- 创建会议时使用用户输入的会议标题，并清理遗留的 Agora 提示文字。
- 增加 512×512 客户端图标资源及可复现的图标生成脚本，修复应用元数据年份和乱码。

## 第四轮认证页与通知已读热修复（2026-08-12）

- 修复深色模式退出登录后，固定浅色登录/注册页的输入框和复选框仍显示为黑色的问题。
- 为认证表单补齐输入框颜色、自动填充语义和浅色控件作用域，不改变用户重新登录后的主题偏好。

- 点击通知时等待服务端确认已读再跳转，列表红点、侧栏徽标和顶部铃铛同步更新。
- 未读数量支持与服务端双向校准，补齐其他设备已读、实时事件遗漏等场景。
